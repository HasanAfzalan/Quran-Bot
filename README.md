# بسم الله الرحمن الرحیم 
### ربات یادآور قرآن روزانه 🕋  
---
قابلیت های کلی: 
- ارسال روزانه صفحه قرآن درون گروه
    - عکس صفحه با ترجمه
    - صوت صفحه با صدای منشاوی
    - پیام یادآور
- ارسال روزانه صفحه قرآن برای همه کاربران گروه به صورت شخصی
- گزارش گیری روزانه از افراد گروه
- گزارش گیری کلی
    - ختم چندم
    - چند صفحه
    - بیشترین مشارکت
- نیازمند ثبت نام اولیه برای اعضای گروه 
---
#### مشخصات فنی:‌
- استفاده از پایگاه داده سبک sqlite که در با اولین راه اندازی ساخته میشود > quran_daily_bot.db
- توسعه داده شده برای سوپر گروه های تلگرام
- روش polling
- رمز درون فایل مشخص شده است. آن را تغییر داده و در اختیار کاربران قرار دهید تا ثبت نام کنند

از آنجایی که از روش polling بهره گرفته شده است این گام ها را برای ران کردن ربات طی کنید:‌
```
git clone https://github.com/HasanAfzalan/Quran-Bot
cd Quran-Bot
sudo pkg install screen
screen -S quran
python3 QuranBot.py
```
پس از اجرای دستورات بالا در ترمینال کلید ترکیبی ``` ctrl + A ``` و سپس کلید ``` D ``` را بزنید. این کار باعث میشود سشن اسکرین مربوطه با نام quran در پس زمینه باز بماند.
